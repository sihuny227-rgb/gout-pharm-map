# 통풍 약리 지도

통풍의 병리 기전을 한 장의 지도로 그리고, 약을 누르면 지도 위에 그 약의 작용 지점이 표시되는 학습용 웹페이지입니다.

**바로 보기:** https://sihuny227-rgb.github.io/gout-pharm-map/

## 지도 구성

| 구획 | 내용 |
| --- | --- |
| ① 요산 생성 (간·조직) | 퓨린 분해 → Hypoxanthine → Xanthine → 요산, XOR, 인간에게 없는 uricase |
| 혈액 | 혈중 요산과 목표치(< 6 mg/dL), 포화 농도(6.8 mg/dL) |
| ② 요산 배설 (신장·장) | 사구체 여과, 재흡수(URAT1 → GLUT9), 분비(OAT → ABCG2·NPT), 장 배설 |
| ③ 결정 침착과 염증 (관절) | MSU 결정 → 대식세포 → NLRP3 → Caspase-1 → IL-1β → IL-1R1 → NF-κB → 호중구 · COX-2/PGE₂ → 급성 발작 |

## 사용법

- **약 버튼**을 누르면 그 약의 작용 지점이 색으로 강조되고 `⊣ 약이름` 표시가 붙습니다. 부가 작용점은 점선, 결과적으로 바뀌는 곳(혈중 요산 ↓, 결정 용해, 요중 요산 ↑ 등)도 함께 표시됩니다.
- **전체 보기**에서는 모든 약의 주 작용점을 한꺼번에 보여 줍니다.
- **지도의 칸**을 누르면 그 단계에서 일어나는 일, 원인, 그곳에 작용하는 약이 나옵니다.
- 지도 아래에서 작용 기전, 쓰는 이유, 부작용과 그 이유, 주의·상호작용을 볼 수 있습니다.

## 다루는 약

- **단기 · 급성 염증 억제:** 콜키신, NSAIDs, 글루코코르티코이드, 아나킨라, 카나키누맙
- **장기 · 요산 저하:** 알로푸리놀, 페북소스타트, 벤즈브로마론, 프로베네시드, 페글로티카제
